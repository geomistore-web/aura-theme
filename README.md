# ثيم أورا (Aura) — Salla Twilight Theme

ثيم فاخر (Luxury) لمتاجر الأزياء والموضة والجمال على منصة سلة، مبني على محرك
Twilight الرسمي. هذا المشروع **نقطة انطلاق حقيقية وقابلة للبناء والنشر** — تم
إنشاؤه من هيكل الثيم الأساسي المفتوح المصدر `theme-raed` (السقالة الرسمية
لسلة لبناء الثيمات)، مع استبدال كامل الطبقة البصرية (الألوان، الخطوط،
التخطيط، أسلوب العرض) بهوية أورا، مع الإبقاء على أكواد الربط الوظيفي
الحقيقية مع منصة سلة (مكوّنات `salla-*`، الفلاتر، الـhooks) كما هي لأنها
البنية الرسمية المطلوبة لأي ثيم يعمل فعليًا.

## ✅ ما هو مكتمل وتم اختباره

- **بنية بناء كاملة تعمل فعليًا**: `npm install && npm run production` تم
  تشغيلها واختبارها هنا بنجاح (webpack + Tailwind + Sass) وأنتجت
  `public/app.css`، `public/app.js`، وباقي الحزم (home / product / checkout /
  pages / order...) بدون أي أخطاء.
- **تغطية كاملة لمجموعات الصفحات التسع** التي توثّقها سلة لأي ثيم:
  1. الرئيسية (Home)
  2. صفحة التصنيف + صفحة المنتج (Product list + single)
  3. السلة (Cart)
  4. صفحات حساب العميل (الملف الشخصي، الطلبات، تفاصيل الطلب، المفضلة،
     الإشعارات، المحفظة)
  5. المدونة (قائمة المقالات + المقال المفرد)
  6. الماركات التجارية (قائمة + صفحة الماركة)
  7. صفحة برنامج الولاء (Loyalty)
  8. صفحة الشكر / تأكيد الطلب (Thank-you)
  9. الصفحات الثابتة / التعريفية (Static / landing pages)
- `twilight.json` كامل: معلومات الثيم، `features`، `settings` (تبديل
  الهيدر/الفوتر الداكن...)، وثلاثة مكونات مخصصة بحقول تخصيص كاملة (بانر
  رئيسي، بانر مزدوج، نشرة بريدية).
- جميع القوالب تستخدم مكوّنات سلة الفعلية ومتغيراتها الحقيقية كما في
  التوثيق الرسمي: `salla-products-list`, `salla-filters`, `salla-slider`,
  `salla-product-options`, `salla-add-product-button`, `salla-quantity-input`,
  `salla-cart-summary-card`, `salla-cart-coupons`, `salla-breadcrumb`,
  `salla-menu`, `salla-orders`, `salla-wallet`, `salla-notifications`,
  `salla-comments`, `salla-loyalty`, `salla-rating-stars`, `salla-payments`...
  إلخ.
- فحص تركيبي (lint) لكل ملفات Twig الثلاثين (30) تأكّد من تطابق `{% %}` /
  `{{ }}` وعدم وجود أكواد غير مغلقة (فحص block/endblock, for/endfor,
  if/endif, set/endset...).
- **مستودع Git مهيأ محليًا** بفرع `main` وأول commit — جاهز للربط بمستودع
  GitHub الذي تنشئه بوابة الشركاء تلقائيًا (انظر خطوات الرفع أدناه).

## ⚠️ ما يستحق المراجعة قبل تقديم طلب النشر النهائي

المشروع الآن يغطي **جميع** مجموعات الصفحات الموثّقة، لكن بعض التفاصيل
تحتاج تحققًا يدويًا لأنه تعذّر تشغيل معاينة فعلية على متجر سلة حقيقي ضمن
هذه الجلسة:

- صفحات حساب العميل، المدونة، الماركات، برنامج الولاء، والصفحة الثابتة
  استُخدم فيها أسلوب "إعادة تنسيق خفيف" (استبدال ألوان/حدود Raed بهوية
  أورا مع الإبقاء على منطق Twig والمكوّنات الحقيقية كما هي) بدل إعادة
  تصميمها بصريًا من الصفر كما فعلنا مع الرئيسية/المنتج/السلة — لأنها
  صفحات وظيفية (حساب، طلبات، محفظة) تعتمد بشكل كبير على مكوّنات سلة
  الجاهزة (`salla-orders`, `salla-wallet`...) التي تُصمَّم من داخل حزمة
  Twilight components نفسها وليس من كود الثيم.
  **يُنصح بمراجعتها بصريًا على متجر تجريبي واحدة تلو الأخرى.**
- ترجمات مخصّصة (`src/locales/ar.json` و`en.json`) — لم يتم إنشاؤها؛
  المفاتيح المستخدمة عبر `trans(...)` تعتمد على قاموس سلة الأساسي (وهو
  يغطي كل المفاتيح المستخدمة هنا لأنها جميعًا مفاتيح رسمية من نظام سلة).
- التحقق من كل أسماء أيقونات `sicon-*` المستخدمة (خصوصًا في صف الثقة
  بصفحة المنتج: `sicon-refresh`, `sicon-shield-check`) مقابل ملف
  `sallaicons.css` الفعلي — معظمها منسوخ حرفيًا من ثيم Raed الرسمي، لكن
  اثنتين لم يتم التحقق منهما ضمن هذه الجلسة.
- تنسيق `salla-add-product-button` عبر `::part(button)` تخمين معقول
  وليس مؤكدًا 100%؛ افحصه في المعاينة الفعلية وعدّله إذا لزم.
- حقل النشرة البريدية شكلي فقط (لا يوجد ربط فعلي لجمع الإيميلات) — يحتاج
  تطبيق تسويقي من سلة أو نقطة نهاية مخصصة.
- لم تُختبر بصريًا على شاشات جوال فعلية بعد (Tailwind يوفر تجاوبًا
  تقريبيًا عبر grid/flex breakpoints).
- سلة تشترط أن يستهدف الثيم صناعة محددة — تم ضبط الوصف والفئة على
  "أزياء وموضة وجمال" في `twilight.json`، عدّلها إذا اخترت مجالًا آخر.
- استضافة الخطوط (Google Fonts محمّل حاليًا عبر `<link>` خارجي في
  `master.twig`) — يُفضّل للإنتاج استضافتها ذاتيًا ضمن `src/assets/styles`.

│       └── pages/

│           ├── thank-you.twig

## التشغيل محليًا

```bash
npm install
npm run watch        # بناء تلقائي أثناء التطوير
npm run production   # بناء نهائي — نفّذه قبل كل رفع/نشر
```

## الخطوات الكاملة: من الرفع إلى الاختبار على متجر تجريبي

### 1) أنشئ الثيم في بوابة الشركاء

1. سجّل الدخول إلى [بوابة شركاء سلة](https://salla.partners) بحساب المطوّر
   الخاص بك.
2. من القائمة الجانبية اذهب إلى **الثيمات (Themes)** ثم اضغط
   **إنشاء ثيم (Create theme)**.
3. عند إنشاء الثيم، تربط البوابة حسابك في **GitHub** تلقائيًا (تحتاج
   صلاحية الوصول لإنشاء مستودعات في حسابك) وتُنشئ لك **مستودع GitHub
   فارغ** مرتبطًا بهذا الثيم، يحتوي مبدئيًا على `twilight.json` أساسي
   فقط.
4. اختر اسم الثيم والصناعة المستهدفة (بما أنك لم تحدد صناعة معينة،
   القيمة الحالية في `twilight.json` هنا هي "أزياء وموضة وجمال" — غيّرها
   إن أردت صناعة أخرى قبل الدفع).

### 2) اربط هذا المشروع بمستودع GitHub الذي أنشأته سلة

من داخل مجلد هذا المشروع (بعد نسخه إلى جهازك أو استخدامه من هنا مباشرة):

```bash
# استبدل الرابط بالرابط الحقيقي لمستودعك الذي أنشأته بوابة الشركاء
git remote add origin https://github.com/<your-username>/<your-theme-repo>.git

# تأكد أن نسخة الإنتاج مبنية قبل الدفع (public/ يجب أن تكون محدّثة)
npm run production

git add -A
git commit -m "Prepare Aura theme for Salla submission"
git push -u origin main
```

> ملاحظة: سلة تخدم أصول الثيم المبنية مباشرة من مجلد `public/` المرفوع في
> المستودع (لهذا هو غير مستثنى في `.gitignore`) — لذلك **لازم تشغّل
> `npm run production` وتتأكد أن `public/` محدّثة قبل كل `git push`**،
> وإلا ستظهر نسخة قديمة أو فارغة من التصميم على المتجر التجريبي.

### 3) عدّل بيانات الثيم الحقيقية قبل الدفع النهائي

في `twilight.json` بدّل القيم التالية (حاليًا نصوص placeholder):

| المفتاح | يستبدل بـ |
|---|---|
| `repository` | رابط مستودع GitHub الفعلي الذي أنشأته سلة |
| `author_email` | بريدك الإلكتروني كمطوّر/دعم فني |
| `support_url` | رابط صفحة الدعم الفني الخاصة بك (أو رابط تواصل) |

### 4) أنشئ متجرًا تجريبيًا واربطه بالثيم للمعاينة الفعلية

1. من بوابة الشركاء، داخل صفحة الثيم الذي أنشأته، ابحث عن خيار **إنشاء
   متجر تجريبي (Demo store)** أو **معاينة (Preview)** — تتيح سلة عادة
   إنشاء متجر تجريبي مجاني مرتبط تلقائيًا بأحدث نسخة مدفوعة (pushed) من
   الثيم.
2. بعد ربط الثيم بالمتجر التجريبي، تصفّح **كل الصفحات المكتملة هنا**
   فعليًا (وليس فقط الرئيسية):
   - الرئيسية، صفحة التصنيف، صفحة المنتج، السلة
   - صفحة تسجيل الدخول → حساب العميل (الملف الشخصي، الطلبات، المفضلة،
     الإشعارات، المحفظة)
   - المدونة (إن كانت مفعّلة في إعدادات المتجر التجريبي) والماركات
   - صفحة برنامج الولاء (إن كانت الميزة مفعّلة على باقتك)
   - إتمام عملية شراء تجريبية للوصول لصفحة الشكر (Thank-you)
   - أي صفحة ثابتة (مثل "من نحن" أو "الشحن والاسترجاع")
3. عدّل بيانات المكونات المخصّصة (البانر الرئيسي، البانر المزدوج،
   النشرة البريدية) من لوحة تحكم "تخصيص الواجهة" في المتجر التجريبي —
   هذه الحقول فارغة افتراضيًا حتى تُملأ يدويًا (راجع الجواب على سؤال
   "هل يطبق تمامًا عند الشراء؟" أدناه).
4. أي تعديل بعد المعاينة: عدّل الكود محليًا → `npm run production` →
   `git add -A && git commit -m "..." && git push` → سلة تُزامن النسخة
   الجديدة تلقائيًا مع نفس المتجر التجريبي المربوط.

### 5) أكمل بيانات العرض وأرسل طلب النشر

بعد التأكد أن كل الصفحات تعمل وتظهر بشكل صحيح على المتجر التجريبي:

1. ارجع لصفحة الثيم في بوابة الشركاء واملأ **بيانات العرض في متجر
   الثيمات**: 3 صور عالية الدقة (1366×768) تعرض تصميم الثيم، وصف
   تسويقي، السعر، ورابط/بيانات الدعم الفني.
2. اضغط **إرسال للمراجعة (Submit for review)**. فريق سلة يراجع الثيم
   (يتحقق من التوافق التقني، اكتمال الصفحات، والالتزام بمعايير الجودة)
   قبل نشره في متجر الثيمات ليصبح متاحًا للشراء من قبل أصحاب المتاجر
   الآخرين.

## نظام أورا البصري (Design Tokens)

معرّف في `:root` داخل `layouts/master.twig` وقابل للاستخدام كطبقة Tailwind
(`bg-aura-gold`, `text-aura-ink`...):

| المتغير | الاستخدام |
|---|---|
| `--aura-bg` / `--aura-bg-soft` | خلفية عاجية دافئة |
| `--aura-ink` / `--aura-ink-soft` / `--aura-muted` | نصوص |
| `--aura-gold` / `--aura-gold-deep` | لون التمييز الذهبي |
| `--aura-dark` / `--aura-dark-2` | أسطح داكنة (الهيدر العلوي، الفوتر) |
| خط العرض | `Markazi Text` (العناوين) |
| خط النص | `Cairo` (الأساسي) |
| خط اللوجو اللاتيني | `Cormorant Garamond` |

> ملاحظة: Google Fonts محمّل عبر `<link>` في `master.twig`. للإنتاج، يُفضّل
> استضافة الخطين ذاتيًا ضمن `src/assets/styles` بدلاً من الاعتماد على
> رابط خارجي، لتفادي أي بطء أو حجب.

## هل يُطبَّق الثيم تمامًا عند شراء تاجر له؟

سؤال مهم يستحق توضيحًا دائمًا في هذا الملف: **التصميم نفسه** (القوالب،
الألوان، التخطيط) يُطبَّق فورًا وبالكامل على أي صفحة من الصفحات
المبنية هنا بمجرد تركيب الثيم. لكن:

- **محتوى المتجر منفصل ومحمي** — صور المنتجات وبيانات التاجر لا تُمسح
  عند تركيب الثيم.
- **الحقول القابلة للتخصيص فارغة افتراضيًا** — نصوص/صور البانر الرئيسي،
  البانر المزدوج، عنوان النشرة البريدية، وخيارات الهيدر/الفوتر الداكن
  يجب أن يملأها كل تاجر بنفسه من لوحة التحكم؛ لن تظهر تلقائيًا بنفس
  المحتوى التجريبي المستخدم هنا للعرض.
- تتيح سلة للتاجر معاينة الثيم وتجربته على نسخة تجريبية قبل نشره فعليًا
  على متجره الحي، فلا مفاجآت.
