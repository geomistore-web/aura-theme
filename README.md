# ثيم أورا (Aura) — Salla Twilight Theme

ثيم فاخر (Luxury) لمتاجر الأزياء والموضة والجمال على منصة سلة، مبني على محرك
Twilight الرسمي. هذا المشروع هو **نقطة انطلاق حقيقية وقابلة للبناء** — تم
إنشاؤه من هيكل الثيم الأساسي المفتوح المصدر `theme-raed` (السقالة الرسمية
لسلة لبناء الثيمات)، مع استبدال كامل الطبقة البصرية (الألوان، الخطوط،
التخطيط، أسلوب العرض) بهوية أورا، مع الإبقاء على أكواد الربط الوظيفي
الحقيقية مع منصة سلة (مكوّنات `salla-*`، الفلاتر، الـhooks) كما هي لأنها
البنية الرسمية المطلوبة لأي ثيم يعمل فعليًا.

## ✅ ما هو مكتمل وتم اختباره

- **بنية بناء كاملة تعمل فعليًا**: `npm install && npm run production` تم
  تشغيلها واختبارها هنا بنجاح (webpack + Tailwind + Sass) وأنتجت
  `public/app.css` و`public/app.js` وباقي الحزم بدون أي أخطاء.
- `twilight.json` كامل: معلومات الثيم، `features` (الخطوط، الألوان،
  الفلاتر، مسار التنقل...)، `settings` (تبديل الهيدر/الفوتر الداكن...)،
  وثلاثة مكونات مخصصة بحقول تخصيص كاملة (بانر رئيسي، بانر مزدوج، نشرة بريدية).
- 4 قوالب Twig حقيقية مطابقة للموك أب المُعتمد سابقًا: **الرئيسية،
  صفحة التصنيف، صفحة المنتج، صفحة السلة** — تستخدم مكوّنات سلة الفعلية:
  `salla-products-list`, `salla-filters`, `salla-slider`,
  `salla-product-options`, `salla-add-product-button`,
  `salla-quantity-input`, `salla-cart-summary-card`, `salla-cart-coupons`,
  `salla-breadcrumb`, `salla-menu`, `salla-social`, `salla-payments`... إلخ.
- الهيدر والفوتر بتصميم أورا الكامل.
- مكونات الصفحة الرئيسية: بانر رئيسي (سلايدر)، بلاطات الأقسام، شريط
  مميزات المتجر، صف المنتجات المميزة (متصل فعليًا بمصدر منتجات حقيقي عبر
  `salla-products-list`)، بانر مزدوج، آراء العملاء، نشرة بريدية.
- فحص تركيبي (lint) لكل ملفات Twig تأكّد من تطابق `{% %}` / `{{ }}` وعدم
  وجود أكواد غير مغلقة.

## ⚠️ ما هو غير مكتمل بعد (مهم قبل الرفع لمتجر الثيمات)

سلة تشترط أن يغطي الثيم **كل** صفحات المتجر القياسية قبل قبوله للنشر. هذا
المشروع يغطي مسار التسوق الأساسي فقط. ينقصك قبل التقديم للمراجعة:

- صفحة الدفع (checkout) وصفحة الشكر / تأكيد الطلب (`thank-you.twig`).
- صفحات حساب العميل بالكامل (الطلبات، المفضلة، العناوين...) — تحتاج
  `layouts/customer.twig` + قوالب `pages/customer/*`.
- صفحة المدونة والمقالة الواحدة، صفحة الماركات التجارية، صفحة تعريفية
  عامة (`page-single.twig`)، صفحة برنامج الولاء إن كان مفعّلاً.
- ترجمات مخصّصة (`src/locales/ar.json` و`en.json`) — لم يتم إنشاؤها هنا؛
  المفاتيح المستخدمة عبر `trans(...)` تعتمد حاليًا على قاموس سلة الأساسي.
- التحقق من كل أسماء أيقونات `sicon-*` المستخدمة (خصوصًا في صف الثقة
  بصفحة المنتج) مقابل ملف `sallaicons.css` الفعلي — بعضها افتراضي لم
  يُتحقق منه ضمن هذه الجلسة.
- تنسيق `salla-add-product-button` عبر `::part(button)` تخمين معقول
  وليس مؤكدًا 100%؛ افحصه في المعاينة الفعلية وعدّله إذا لزم.
- حقل النشرة البريدية شكلي فقط (لا يوجد ربط فعلي لجمع الإيميلات) — يحتاج
  تطبيق تسويقي من سلة أو نقطة نهاية مخصصة.
- لا توجد نسخة "جوال" منفصلة بالتصميم — Tailwind مفعّل والتخطيطات
  الأساسية متجاوبة تقريبيًا (grid يتحول لعمود واحد)، لكن لم تُختبر بصريًا
  على شاشات فعلية بعد.
- سلة تشترط أن يستهدف الثيم صناعة محددة — تم ضبط الوصف والفئة على
  "أزياء وموضة وجمال" في `twilight.json`، عدّلها إذا اخترت مجالًا آخر.

## البنية

```
aura-theme/
├── twilight.json              ← إعدادات الثيم، المكونات المخصصة
├── package.json / webpack.config.js / tailwind.config.js / postcss.config.js
├── src/
│   ├── assets/
│   │   ├── js/                ← أكواد الربط مع منصة سلة (من theme-raed، بلا تعديل تصميمي)
│   │   ├── styles/
│   │   │   ├── app.scss       ← نقطة الدخول (Tailwind + جزئيات أورا)
│   │   │   └── aura/          ← التصميم الفعلي لهوية أورا (ألوان، خطوط، كل صفحة)
│   │   └── images/
│   └── views/
│       ├── layouts/master.twig
│       ├── components/
│       │   ├── header/header.twig
│       │   ├── footer/footer.twig
│       │   └── home/*.twig    ← مكونات الصفحة الرئيسية
│       └── pages/
│           ├── index.twig
│           ├── cart.twig
│           ├── product/{index,single}.twig
│           └── partials/product/options.twig
└── public/                    ← ناتج البناء (مبني بالفعل هنا — أعد بناءه بعد أي تعديل)
```

## التشغيل محليًا

```bash
npm install
npm run watch        # بناء تلقائي أثناء التطوير
npm run production   # بناء نهائي — نفّذه قبل كل رفع/نشر
```

## الخطوات الفعلية للرفع عبر حساب الشركاء

1. في بوابة شركاء سلة (partners.salla.sa) اضغط **Create theme** — هذا
   يُنشئ مستودع GitHub فارغًا مرتبطًا بحسابك مع `twilight.json` أولي.
2. استنسخ (clone) ذلك المستودع، ثم انسخ محتويات هذا المجلد بالكامل فوقه
   (بما فيها `public/` بعد تشغيل `npm run production`).
3. عدّل في `twilight.json`: `repository`, `author_email`, `support_url`
   بالقيم الحقيقية الخاصة بك (حاليًا نصوص placeholder).
4. ادفع (`git push`) — يتزامن هذا مع بوابة الشركاء تلقائيًا.
5. أنشئ متجرًا تجريبيًا من البوابة واربط الثيم به للمعاينة الفعلية.
6. بعد التأكد من الصفحات الناقصة (أعلاه) وإتمامها، أكمل بيانات العرض
   (3 صور HD 1366×768، السعر، بيانات الدعم) وأرسل **طلب النشر**.

## نظام أورا البصري (Design Tokens)

معرّف في `:root` داخل `layouts/master.twig` وقابل للاستخدام كطبقة Tailwind
(`bg-aura-gold`, `text-aura-ink`...):

| المتغير | الاستخدام |
|---|---|
| `--aura-bg` / `--aura-bg-soft` | خلفية عاجية دافئة |
| `--aura-ink` / `--aura-ink-soft` / `--aura-muted` | نصوص |
| `--aura-gold` / `--aura-gold-deep` | لون التمييز الذهبي |
| `--aura-dark` / `--aura-dark-2` | أسطح داكنة (الهيدر العلوي، الفوتر) |
| خط العرض | `Markazi Text` (العناوين) |
| خط النص | `Cairo` (الأساسي) |
| خط اللوجو اللاتيني | `Cormorant Garamond` |

> ملاحظة: Google Fonts محمّل عبر `<link>` في `master.twig`. للإنتاج، يُفضّل
> استضافة الخطين ذاتيًا ضمن `src/assets/styles` بدلاً من الاعتماد على
> رابط خارجي، لتفادي أي بطء أو حجب.
